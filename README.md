# Миникрафт в браузере

Небольшая песочница в стиле Minecraft на чистом HTML/CSS/JS.

## Что есть
- Блочный мир 25x15.
- ЛКМ удаляет блоки.
- ПКМ ставит выбранный блок.
- Клавиши `1-5` или кнопки сверху меняют материал.

## Запуск
Из папки проекта:

```bash
python3 -m http.server 8000
```

После этого открыть: `http://localhost:8000`.
